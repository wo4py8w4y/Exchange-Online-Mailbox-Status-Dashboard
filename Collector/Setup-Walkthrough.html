MailboxDashboard setup walkthrough

This guide follows the current collector pipeline. Older collector scripts are retained under Collector/Legacy for reference only.

Prerequisites

  • Windows PowerShell 5.1 or PowerShell 7 (PowerShell 7 is recommended)
  • Exchange Online administrator access
  • Permission to create or update an Entra app registration when required
  • ExchangeOnlineManagement
Install-Module ExchangeOnlineManagement -Scope CurrentUser
Install-Module Microsoft.Graph.Authentication -Scope CurrentUser
Install-Module graph.auth.lite -Scope CurrentUser
Install-Module Microsoft.PowerShell.ThreadJob -Scope CurrentUser

Only ExchangeOnlineManagement is required for sequential collection. ThreadJob is required only for -Parallel.

1. Initialize

.\Collector\Initialize-MailboxDashboard.ps1

The wizard creates or checks the configuration, folders, and Mailboxes/mailboxes.csv. Use -Force to replace an existing configuration.

.\Collector\Initialize-MailboxDashboard.ps1 `
    -Organization contoso.onmicrosoft.com `
    -AppId 00000000-0000-0000-0000-000000000000 `
    -AuthenticationMode Certificate `
    -Unattended

Replace the sample mailbox rows with the mailboxes to collect.

2. Configure authentication

Set Organization, AppID, and Authentication.Mode in Collector/Config/dashboardConfig.json. Certificate mode needs a client secret or certificate thumbprint; delegated mode needs UserPrincipalName.

.\Collector\Register-EntraApp.ps1 `
    -ConfigPath .\Collector\Config\dashboardConfig.json

Use Certificate or client-secret authentication for scheduled or parallel collection. Use Interactive or Delegated for manual runs. Auto displays the runtime menu.

3. Test without Exchange Online

.\Collector\Invoke-MailboxDashboardCollection.ps1 -TestData

This overwrites Web/history.json and Web/data.json. To create demo files without replacing live data, run New-MailboxDashboardTestData.ps1 without -Live.

4. Collect

.\Collector\Invoke-MailboxDashboardCollection.ps1

The default is sequential. For app-only parallel collection:

.\Collector\Invoke-MailboxDashboardCollection.ps1 -Parallel -ThrottleLimit 8

Parallel workers write to Collector/Temp/ThreadJobs and require certificate or client-secret authentication.

5. Validate and repair

.\Collector\Test-MailboxDashboardJSON.ps1
.\Collector\Test-MailboxDashboardJSON.ps1 -Repair
.\Collector\Test-MailboxDashboardJSON.ps1 -Repair -Cull
.\Collector\Test-MailboxDashboardJSON.ps1 -Repair -RestoreSamplesFromData
.\Collector\Test-MailboxDashboardJSON.ps1 -Strict
.\Collector\Generate-MailboxSnapshot.ps1

Use the snapshot command when history is correct but the overview data is stale.

Licensing status is collected from Exchange during a fresh collection. Older records without licensing metadata are shown as unknown until they are recollected.

6. Browse locally

.\Web\HTTPServer.ps1 -RootPath .\Web -Prefix http://localhost:8888/

Open http://localhost:8888/.

Troubleshooting

  • Check behind the terminal if interactive sign-in appears to hang.
  • For failed collections, inspect Collector/Logs/failures.log and exports.log.
  • For an empty dashboard, regenerate the snapshot and run the validator.
  • For 404s, confirm the server root is Web and the browser port matches -Prefix.
